# Digital Clock

A simple and responsive Digital Clock built using HTML, CSS, and JavaScript. The application displays the current time and date in real-time with a clean and modern user interface.

## Features

- Real-time clock updates every second
- Displays the current date
- Modern dark-themed design
- Responsive layout
- Lightweight and beginner-friendly project

## Technologies Used

- HTML5
- CSS3
- JavaScript
